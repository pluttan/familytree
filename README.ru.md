# Family Tree

**Интерактивный конструктор семейного дерева с визуализацией на D3.js**

</div>

Веб-приложение для построения и изучения семейных деревьев. Дерево отображается в виде SVG-диаграммы на D3.js с масштабированием и перемещением. Каждый узел содержит полную карточку человека — фото, даты, город, описание — редактируемую через перетаскиваемое боковое меню. Поддерживаются аккаунты, несколько семей и семь языков интерфейса.

## ■ Возможности

- ❖ **Дерево на D3.js** — анимированное SVG-дерево с зумом, панорамированием и плавными переходами; узлы сворачиваются и разворачиваются
- ❖ **Редактирование узлов** — добавление и удаление узлов, переключение видимости поддерева через инструменты на панели
- ❖ **Карточки людей** — загрузка фото, даты рождения и смерти, город, описание, индивидуальный цвет карточки и цвет линии связи для каждого узла
- ❖ **Аккаунты** — регистрация и вход с AES-шифрованием паролей; сессия сохраняется через cookie-хэш
- ❖ **Несколько семей** — каждый аккаунт может хранить несколько независимых семейных деревьев
- ❖ **Многоязычный интерфейс** — семь языков: английский, русский, немецкий, итальянский, испанский, японский, китайский
- ❖ **Перетаскиваемое меню** — боковая панель перемещается за заголовок

## ■ Как это работает

```
1. Компонент React Tree инициализирует D3-лэйаут при монтировании, затем перерисовывает дерево при изменении состояния через паттерн enter/update/exit.
2. Express-сервер предоставляет единый /api-эндпоинт, принимающий SQL-фрагменты (select, insert, update, delete), которые пробрасываются в PostgreSQL.
3. При регистрации пароль шифруется через CryptoJS AES; при входе проверяются учётные данные и выдаётся хэш, сохраняемый в cookie браузера.
4. JSON дерева сериализуется и хранится в таблице fam; данные о людях — в таблице person; изображения загружаются на диск сервера.
```

## ■ Использование

```bash
# Бэкенд (Node.js + Express + PostgreSQL)
npm install
npm start

# Фронтенд (React) — в отдельном терминале
npm install
npm start
```
